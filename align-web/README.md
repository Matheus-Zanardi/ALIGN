# ALIGN Web

Frontend MVP do ALIGN em React + Vite.

## Rodar localmente

1. Deixe a API Spring Boot rodando em `http://localhost:8080`.
2. Instale as dependências: `npm install`
3. Inicie o front: `npm run dev`
4. Abra `http://localhost:5173`.

A URL da API pode ser alterada copiando `.env.example` para `.env` e mudando `VITE_API_URL`.
